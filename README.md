# 🐾 WinDash

Локальна панель керування й діагностики Windows: моніторинг із тригерами, AI-консоль на Claude, драйвери, пресети та автовідкат змін. Один PowerShell-скрипт і одна HTML-сторінка — без встановлення й залежностей.

> **English:** WinDash is a local Windows dashboard (a single PowerShell script + one HTML page, no dependencies). It monitors the machine, lets Claude write and diagnose with PowerShell under a safety net (static script analysis, state snapshots, auto-rollback), finds and installs drivers, and keeps a log of incidents. The UI is in Ukrainian.

## Можливості

- 📊 **Панель** — CPU, RAM, диски, аптайм, батарея, топ процесів, стан служб. Віджети можна вмикати й перетягувати, є світла/темна тема й акцентні кольори.
- ✨ **AI-консоль** — два режими:
  - *Скрипт*: опишіть задачу словами, Claude пише PowerShell, ви переглядаєте й запускаєте.
  - *Агент*: діагностує крок за кроком (до 8 кроків), безпечні кроки «лише читання» виконує без підтвердження, виправлення пропонує окремим кроком.
- 🛡 **Страховка перед запуском** — статичний аналіз скрипта (AST) з рівнем ризику й переліком служб та ключів реєстру, які він зачепить; режим «лише читання»; знімок стану; автовідкат при помилці; вікно «Зберегти зміни?» (відкат, якщо не підтвердити вчасно); точка відновлення Windows для скриптів високого ризику.
- 🎛 **Пресети** — вбудовані («Відновити системні служби», «Прибирання тимчасових файлів», «Перезапуск мережі») та власні, з оцінками ⭐, імпортом і експортом у JSON.
- 🧩 **Драйвери** — пошук пристроїв із проблемами; джерела по черзі: Windows Update → Microsoft Update Catalog за Hardware ID → підказка сайту виробника. Встановлення з папки, відкат нових драйверів, щоденний фоновий пошук.
- 🚨 **Тригери** — високе навантаження CPU й RAM, мало місця на диску, помилки журналу System, пристрої з проблемою драйвера, вимкнені ключові служби (Windows Update, BITS, EventLog, CryptSvc, TrustedInstaller, RpcSs). Сповіщення Windows і автозапуск при вході через Планувальник завдань.
- 📈 **Аналітика** — стрічка інцидентів, графік CPU/RAM за 24 години, історія запусків, знімки й відкат.

## Вимоги

- Windows 10 або 11 з вбудованим Windows PowerShell 5.1.
- Права адміністратора — для керування службами, встановлення драйверів і автозапуску (решта працює й без них).
- Ключ [Anthropic API](https://console.anthropic.com/) — лише для AI-консолі, решта працює без нього.

## Запуск

```bash
git clone https://github.com/gregnevm/windash.git
cd windash
```

Запустіть `start.cmd` — він перезапустить скрипт від імені адміністратора й відкриє панель на <http://127.0.0.1:8787/>.

Без прав адміністратора:

```powershell
powershell -ExecutionPolicy Bypass -File .\windash.ps1
```

Параметри: `-Port 8787` (порт), `-NoBrowser` (не відкривати браузер).

API-ключ вкажіть у **Налаштування → AI (Claude)** або в змінній середовища `ANTHROPIC_API_KEY`.

## Налаштування

Усе, що є в розділі «Налаштування», зберігається у `config.json` поруч зі скриптом. Файл створюється при першому збереженні; зразок із типовими значеннями — [`config.example.json`](config.example.json).

| Ключ | За замовчуванням | Що робить |
|---|---|---|
| `apiKey` | `""` | Ключ Anthropic (або змінна `ANTHROPIC_API_KEY`) |
| `model` | `claude-sonnet-5-5` | Модель Claude |
| `cpu` | `90` | Поріг CPU, %: інцидент, коли перевищено кілька хвилин поспіль |
| `ram` | `90` | Поріг заповнення памʼяті, % |
| `disk` | `10` | Інцидент, коли вільного місця на диску менше, % |
| `evt` | `5` | Інцидент, коли помилок журналу System за годину не менше |
| `cooldown` | `15` | Пауза між повторами інциденту одного типу, хв |
| `autoRollback` | `1` | Відкотити зміни, якщо скрипт завершився з помилкою |
| `confirmSec` | `60` | Вікно «Зберегти зміни?», с (`0` — вимкнено) |
| `autoRestore` | `1` | Точка відновлення перед скриптом високого ризику |
| `notify` | `1` | Сповіщення Windows про інциденти |
| `drvAuto` | `1` | Драйвери раз на добу: `0` — вимкнено, `1` — шукати й сповіщати, `2` — шукати й встановлювати |

## Безпека

- Сервер слухає **лише `127.0.0.1`**. Кожен запит до API вимагає випадковий токен, який створюється при кожному запуску й вбудовується тільки в сторінку, тож інші сайти не можуть керувати панеллю.
- WinDash **виконує PowerShell-скрипти** від імені користувача, а через `start.cmd` — адміністратора. Скрипти від AI читайте перед запуском: аналіз, знімки й автовідкат зменшують ризик, але не гарантують захисту.
- AI-режим надсилає в Anthropic API ваш запит, короткий опис машини (ОС, модель ПК, CPU, RAM) і, в режимі агента, вивід виконаних кроків. Не запускайте агента там, де вивід команд може містити секрети.
- API-ключ лежить у `config.json` **відкритим текстом**. Файл виключено з git через `.gitignore`, не публікуйте його.
- Режим `drvAuto = 2` сам завантажує драйвери з Microsoft Update Catalog і встановлює їх. Вмикайте його свідомо.

## Дані

Усе, що створює WinDash, лежить у `logs\` поруч зі скриптом (виключено з git): метрики CPU/RAM (`metrics-*.csv`, зберігаються 30 днів), інциденти й запуски (`*.jsonl`), знімки та вивід фонових задач (60 днів). Кнопка «🧹 Очистити» в Аналітиці видаляє логи.

## Структура

| Файл | Призначення |
|---|---|
| `windash.ps1` | Сервер: HTTP API, монітор тригерів, аналіз скриптів, знімки й відкат, драйвери, виклики Claude |
| `index.html` | Інтерфейс (вся клієнтська логіка в одному файлі) |
